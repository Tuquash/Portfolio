## Selected projects

### RevenueForge — Lead management dashboard
A browser-based lead-management application using Supabase authentication and PostgreSQL.

- Lead creation, editing, deletion and status tracking
- Search/filtering and dashboard summaries
- Follow-up message templates (not automatically sent)
- Supabase-backed user data; access depends on correctly configured Row Level Security

[Open repository](https://github.com/Tuquash/RevenueForge) · [Live demo](https://tuquash.github.io/RevenueForge/)

### Bob-AI — Whisky discovery prototype
A local catalogue-search prototype that matches bottle, region and flavour keywords against sample whisky records. It is not connected to a live AI model, BAXUS, retailer inventory or real-time pricing.

[Open repository](https://github.com/Tuquash/Bob-AI) · [Live demo](https://tuquash.github.io/Bob-AI/)

### Narrative Hunter V3 — Solana token research scanner
A Python research tool that screens public token-market data, applies configurable filters and can send Telegram alerts. It does not execute trades and its scores are not investment advice or predictions.

[Open repository](https://github.com/Tuquash/Narrative-Hunter-V3)

### AgentGuard NEAR — transaction policy prototype
An experimental interface for evaluating simulated agent transactions against spending limits and policy rules. Treat decisions as a prototype until the application is connected to a verified transaction-signing or execution layer.

[Open repository](https://github.com/Tuquash/AgentGuard-NEAR)
