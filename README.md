## Projects

### 1. RevenueForge — Lead Management Dashboard

A lead management application built to organise and track business leads.

Features:
- User authentication with Supabase
- Create, edit, and delete leads
- Lead status tracking
- Search and filtering
- Follow-up message generator
- Basic reports and dashboard

**Limitations:** Follow-up messages are generated as templates and are not automatically sent. The project does not currently include payment processing or external CRM integrations.

- [Live Demo](https://tuquash.github.io/RevenueForge/)
- [GitHub Repository](https://github.com/Tuquash/RevenueForge)

### 2. Bob-AI — Whisky Discovery Prototype

A whisky discovery concept designed to help users explore bottles and receive recommendations.

The current demo uses sample responses. It does not yet connect to a live AI recommendation engine, BAXUS API, or real-time whisky pricing database.

- [Live Demo](https://tuquash.github.io/Bob-AI/)
- [GitHub Repository](https://github.com/Tuquash/Bob-AI)

### 3. Narrative Hunter V3 — Solana Token Research Bot

A Python-based research and monitoring tool for discovering Solana tokens and identifying potential risk indicators.

Features:
- Token discovery using public market data sources
- Liquidity and volume screening
- Risk indicators and scoring
- Telegram alert integration
- Price milestone monitoring

**Important:** This is a signal and research tool. It does not execute trades or guarantee profitable outcomes.

- [GitHub Profile](https://github.com/Tuquash)
